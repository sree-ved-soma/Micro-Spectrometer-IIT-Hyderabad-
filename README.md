# Micro-Spectrometer-IIT-Hyderabad
Project : Working Micro-Spectrometer Model 

Led two sequential project teams across two semesters — first building a 40x magnification optical microscope in Sem 3, then leading a separate team to upgrade the system into a fully functional spectrometer in Sem 4. The final integrated system captures high-resolution specimen images and simultaneously analyses their spectral characteristics using an endoscope camera and Python-based data processing.

Team Leadership: Led two distinct teams across consecutive semesters — Semester 3 team focused on microscope assembly, Semester 4 team focused on spectrometer integration and software development.

Optical & Spectrometer Integration: Coupled a 40x objective lens for sample magnification with a transmission diffraction grating to split transmitted light into its constituent wavelengths.

Hardware Design: Designed a rigid, light-tight custom housing using Solid Edge and fabricated the physical structure using Creality for 3D printing, ensuring precise optical alignment between the lens, grating, and camera.

Software & Data Analysis: Developed Python scripts using OpenCV for image processing, NumPy for spectral data extraction, and Matplotlib to plot intensity-versus-wavelength graphs for material characterisation.
